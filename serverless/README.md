## 접수된 피드백 확인

[관리자 피드백함](https://lunacapture-feedback-hyundong.undong.chatgpt.site/admin)을 열고 **ChatGPT로 로그인**을 누릅니다. `hyundongy@gmail.com` 계정만 열람할 수 있습니다. 다른 계정으로 로그인했다면 로그아웃 후 관리자 계정으로 다시 로그인합니다. 공개 첫 화면의 **관리자 로그인** 링크로도 들어갈 수 있습니다.

최신 접수순 목록, 접수 시각(한국 시간), 앱 버전, 선택 이메일을 표시합니다. 한 페이지 25건이며 이전·다음 이동과 새로고침을 지원합니다. 이메일 링크는 답장용 기본 메일 앱을 엽니다. 로그인과 관리자 권한은 매 요청 서버에서 검사하며, 관리자 응답은 캐시하지 않습니다. 앱의 익명 접수 API는 그대로 유지합니다.

이 채팅에서 “접수된 피드백 보여줘”라고 요청해도 확인할 수 있습니다.

`content`는 내용, `reply_to`는 선택 이메일, `version`은 앱 버전, `created`는 접수 시각(Unix 초), `id`는 중복 방지용 요청 번호입니다. 메일 알림은 발송하지 않습니다. 답장이 필요하면 입력된 이메일로 직접 답장합니다.

연결 검증용 테스트 1건(`dbfa518b57594b31903b73d47daf0001`)이 들어 있습니다. 실제 사용자 의견과 구분해 주세요.

## 운영 및 재배포

`feedback-api/`는 배포한 소스의 사본입니다. 설치·빌드 산출물, 인증 정보 및 실제 접수 내용은 포함하지 않습니다. 전용 Sites 소스 저장소 커밋: `d2dcf0d1ab8710fd85076b7bcbce96424a001869`.

수정 시 Sites 스킬의 기존 프로젝트 열기 절차로 위 프로젝트 소스 저장소를 열고 변경을 반영한 후 저장·배포합니다. 새 프로젝트를 만들지 마세요. 이 사본도 함께 갱신해 주세요.

```powershell
cd serverless/feedback-api
npm ci
node --test app/api/feedback/core.test.mjs app/admin/policy.test.mjs
npm run build
```

스키마 변경은 `db/schema.ts` 수정 → `npm run db:generate` → 생성된 `drizzle/` 검토 순서입니다. 호스팅 배포가 마이그레이션을 적용합니다. 적용한 마이그레이션을 수정하지 않습니다.

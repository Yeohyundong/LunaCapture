LunaCapture {VERSION} — 가벼운 화면 캡처 · GIF · 동영상 녹화
================================================================

■ 설치
  1. LunaCapture.exe 를 더블클릭하세요.
  2. "Windows의 PC 보호" 파란 창이 뜨면 → [추가 정보] → [실행] 을 누르세요.
     (처음 보는 프로그램이라 윈도우가 확인하는 것이고, 문제가 있다는 뜻은 아니에요)
  3. "LunaCapture 설치" 창에서 [설치하기] 를 누르면 끝!
     - 시작 메뉴에 LunaCapture가 생겨요
     - 관리자 권한 없이 내 계정에만 설치돼요
     - 설치 없이 그냥 쓰고 싶으면 [설치 없이 실행]

  실행되면 작업 표시줄 오른쪽 아래(트레이)에 보라색 달 아이콘이 생겨요.

■ 사용법
  PrtSc            캡처 화면 열기 (사진 모드로 시작)
  Tab              사진 ↔ 녹화 모드 전환
  드래그 / 클릭     영역 선택 / 창 선택
  Enter            전체 화면(사진) · 이 모니터(녹화)
  Esc              취소
  Shift+PrtSc      캡처 기록 (최근 캡처·녹화 100개, 사진은 다시 편집 가능)
                   편집 창 오른쪽에도 기록 목록이 있어요 (위쪽 '기록' 버튼으로 열고 닫기)

  · 사진: 캡처하면 클립보드에 복사되고 자동 저장돼요. 이어서 편집 창이 열려요.
          새 편집 창을 열면 이전 편집 창은 편집 내용을 저장하고 닫혀요.
          이전 캡처는 기록 목록에서 다시 열 수 있어요.
          편집 창을 원하는 곳에 옮겨 두면 다음 캡처도 같은 위치·크기로 열려요.
  · 녹화: 영역을 고르면 설정 창에서 GIF / 동영상(MP4)을 고르고
          목표 용량(예: 10MB)을 정하면 알맞은 설정을 추천해 줘요.
          녹화 중 PrtSc 를 한 번 더 누르면 멈춰요.

■ 편집 창의 영역 선택 (왼쪽 두 번째 점선 네모 버튼, 단축키 E)
  영역을 끌어서 잡으면 아래에 버튼이 나와요.
  복사 (Ctrl+C)      선택 영역만 클립보드에
  저장 (Ctrl+S)      선택 영역만 파일로
  오려내기 (Ctrl+X)  떼어 내서 끌어 옮기기 (빈 자리는 주변 색으로 채워요)
  자르기             선택 영역만 남기기 (그려 둔 것도 계속 고칠 수 있어요)
  강조               선택 영역만 밝게, 나머지는 어둡게 (여러 곳 가능)
  Ctrl+V             클립보드의 그림 붙여넣기 · Ctrl+A 전체 선택
  모두 Ctrl+Z 로 되돌릴 수 있어요.

■ 편집 도구와 글자 크기
  도형 (R): 3×3 선택창에서 사각형·둥근 사각형·원(행)과 테두리·채움·반투명(열)을 골라요.
  색상: 위쪽 색상 원을 누르면 My color·추천 컬러·기본 팔레트가 열려요.
        My color의 +를 누르면 별도 상세 팝업이 열려요.
        색상 영역·색조·투명도 또는 HEX/RGBA 값을 설정하고 스포이드로 화면 색도 추출해요.
        스포이드는 화면을 클릭해 선택, Esc 또는 오른쪽 클릭으로 취소해요.
        HEX는 #RRGGBB 또는 #RRGGBBAA, A는 0~100%예요.
        확인하면 맞춤 색상(최근 24개)에 저장돼요. 마지막 선택 색상도 기억해요.
        추천 컬러의 팔레트 선택에서 9가지 무드(각 6색) 중 하나를 고르면 계속 고정돼요.
  번호 (N): 테두리 없는 원형·사각형·광택 사각형 중 고르고 클릭하면 다음 번호가 생겨요.
        광택 사각형은 배지와 영역 선에 은은한 그림자·하이라이트를 더해요.
        클릭한 채 끌면 번호가 안쪽 모서리에 놓인 사각 영역을 그려요.
        배지 위치에서 시작 꼭짓점 주변 네 사분면 중 하나를 골라요.
        아이콘의 L자 선이 영역 박스예요. 그리는 방향에 따라 배지도 좌우·상하 반전돼요.
        마지막 설정을 기억하고 새 번호에 적용해요. 기존 번호를 선택한 상태에서도 변경돼요.
        글자 A−/A+ 또는 상단 글자 크기로 번호 폰트를 조절하면 배지가 글자에 맞춰져요.
        여러 자리 번호도 폰트 크기를 유지하며 배지가 자동으로 커져요. 선 굵기는 별개예요. 영역 박스의 네 모서리를 끌어서 크기를 조절해요.
        사각 배지는 테두리에 붙고 원형 배지는 2px 여백이 생겨요.
        번호를 더블클릭하면 배지 안에서 바로 입력해요 (중복 허용).
        Enter로 확정, Esc로 취소하며 다른 곳을 클릭해도 확정돼요.
        새 번호는 현재 그림의 가장 큰 번호 + 1이며 변경은 Ctrl+Z로 되돌려요.

  위쪽 A− / A+ 버튼으로 글자 크기를 8~144 사이에서 2씩 조절해요.
  가운데 숫자(px)는 현재 크기예요. 선 굵기와 따로 조절할 수 있어요.
  텍스트·말풍선·사각형·원 안의 글자 모두 적용돼요.
  입력 중 버튼을 누르면 바로 반영되고, 작성한 글자는 클릭해서 선택한 뒤 조절해요.
  선택한 글자의 크기 변경은 Ctrl+Z로 되돌릴 수 있어요.
  다음에 새로 입력하는 글자에도 마지막으로 조절한 크기가 적용돼요.

■ 처음 실행할 때 "PrtSc 키 설정" 창이 뜨면
  다른 프로그램(캡처 도구, PicPick 등)이 PrtSc 를 쓰고 있다는 뜻이에요.
  [우선 사용] 을 누르면 LunaCapture가 PrtSc 를 받아요.

  동영상   : 동영상\LunaCapture

  설치된 앱은 실행 시와 하루 한 번 새 버전을 확인해요.
  다운로드 후 편집·캡처·녹화·GIF 자르기 등 작업 창이 모두 닫히면 적용하고 다시 실행돼요.
  업데이트 때문에 작업 중인 창을 강제로 닫지 않아요. 설정과 캡처 기록은 그대로 유지해요.
  트레이 → '업데이트 확인'으로 직접 확인하거나 설정에서 자동 업데이트를 끌 수 있어요.
  설치 없이 실행하는 포터블 파일은 자동으로 교체하지 않아요.
  자동 업데이트가 없는 구버전은 한 번만 새 파일로 설치해야 해요.
  기존 앱의 작업을 마무리하고 트레이에서 종료한 뒤 새 LunaCapture.exe 를 실행하세요.
